# Test Tasks (T1–T10)

The ten required tasks from `16_VALIDATION/UX_VALIDATION.md`, scripted for
both conditions. The task bar in the UI tags events with the active task.
Verbalize while working (think-aloud).

| # | Task | SystemVirtue condition | Baseline condition | Success |
| --- | --- | --- | --- | --- |
| T1 | Find a capability | Find a tool that can search the web. | Same. | Reaches `capability/web-search` or `tool/brave-web-search`. |
| T2 | Discover an unknown capability | Find a capability you did not know existed and name it. | Same. | Names a capability genuinely new to them (pre-task inventory recorded). |
| T3 | Compare alternatives | Compare two web-information tools and pick one for research. | Compare using only directory pages. | Justified choice; comparison support used in S. |
| T4 | Understand a relationship | Explain how the GitHub MCP Server relates to `search_code`. | Same question. | Correctly describes EXPOSES relationship. |
| T5 | Determine availability | Where can Claude models be used from? | Same question. | Identifies provider/hosting (S: via HOSTED_BY/claims). |
| T6 | Return to earlier exploration | Go back to the memory server you looked at earlier. | Same. | Arrives without re-searching from scratch. |
| T7 | Explain a recommendation | Get a recommendation for web research and say why it was made. | Attempt the same. | S: states reasons + uncertainty. B: records inability. |
| T8 | Identify uncertainty | Find a claim the system is not fully sure about. | Attempt the same. | S: finds conditional/escalated claim. B: records inability. |
| T9 | Without visualisation | Repeat T1 with the relationship view disabled. | (Baseline has no visualisation.) | Same success as T1. |
| T10 | With accessibility features | Repeat T1 using keyboard only (no mouse). | Same. | Task completed keyboard-only. |

## Pre-task inventory (for T2)

Before the session, ask the participant to list web/agent tools they already
know. Anything not on that list that they find in T2 counts as a discovery.

## Task end

The participant clicks **Task completed** or **Could not complete** in the
task bar; the researcher notes observed difficulty (1–5) in the log sheet.

## Post-task probes (each task)

- "Where are you right now, and why is it relevant?" (context retention)
- "How confident are you that this is the right choice?" (0–100; calibration)
